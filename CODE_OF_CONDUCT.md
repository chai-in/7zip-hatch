# Code of conduct

## Participation

Treat people with respect, regardless of background, identity, experience,
disability, or communication style. Give technical feedback about the work,
explain disagreements, and make room for questions and corrections.

Harassment, threats, discriminatory remarks, sexualized attention, doxxing,
and deliberate disruption are not welcome. Do not publish another person's
private information. Respect boundaries when someone asks a conversation to
stop. These expectations apply in project issues, pull requests, discussions,
and other spaces used to represent this project.

## Reporting

For a concern that is safe to discuss publicly, contact
[@chai-in](https://github.com/chai-in) through a project issue. For a sensitive
incident, use a [private contact request](https://github.com/chai-in/7zip-hatch/issues/new?template=private_contact.yml).
That issue is public: include no incident details, names, or private contact
information. It only asks the maintainer to arrange a private channel before
details are shared. The project does not currently operate a dedicated private
conduct-report inbox.

Abuse on GitHub can also be reported directly through
[GitHub's abuse reporting process](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
Security vulnerabilities use the separate [private security process](SECURITY.md).

## Enforcement

The maintainer is responsible for moderation and can clarify expectations,
request corrections, remove harmful content, or temporarily or permanently
restrict participation. The response should fit the behavior and its impact.
Retaliation against people who raise concerns is itself a violation.

Reports are shared only as needed for moderation. Avoid repeating private
details in public discussion. Responses depend on volunteer availability;
this policy does not promise confidentiality beyond the practical limits
of the reporting channel or a fixed response time.
